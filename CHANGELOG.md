# Changelog

## 0.1.0 — 2026-10-23

Initial public release.

- Click-to-pick annotation mode for the DSH Desktop built-in side browser.
- Numbered page markers with a popover to view, edit, and delete annotations.
- Synced annotation panel above the composer with edit/delete/clear.
- Precise payload: page URL, verified CSS selector, XPath, stable attributes, DOM, best-effort source hint, note, attribute/text diffs.
- Compact annotation chip in the composer and a compact expandable card in the transcript.
- Apple-style in-page UI with automatic light/dark and a manual theme toggle; editable element attributes and text.
- Click-outside/Escape exit; client-only implementation with no Host services, network calls, or telemetry.
